# Mesh Վարվելակերպ և Լավագույն Փորձառույթ

Համագործակցային վարվելակերպը ապահովում է, որ mesh-ը մնա արագ և հուսալի։

## 1. Սարքի Դերեր
- **`CLIENT`**: Ստանդարտ ռաշակիր հանգույցների համար։
- **`CLIENT_MUTE`**: Տնային հանգույցների համար։
- **`CLIENT_BASE`**: Տնային կայան հանգույցների համար։
- **`ROUTER`**: Միայն բարձր տանիքների (9+ հարկ) կամ լեռնագագաթների համար։

## 2. Հանգույցի Անվանում
- Առանց էմոջի, միայն անգլերեն (ASCII), մինչև 15 սիմվոլ։

## 3. GPS Պոզիցիայի Հեռարկման Ընդմիջակներ
- Միացրեք **Smart Position** ռաշակիր հանգույցների համար։
- Անշարժ հանգույցներ: 30–120 րոպե ընդմիջակ։

## 4. Տելեմետրիա
- Անջատեք տնային հանգույցների համար կամ մեծացրեք ընդմիջակը 2–6 ժամ։

## 5. MQTT Վարվելակերպ
- **Downlink-ը միացրեք հանգույցների վրա**: Սա կհաղետի տեղական սպեկտրը։
- Օգտագործեք տարածաշրջանային թեման `/msh/EU_868/AM/`։

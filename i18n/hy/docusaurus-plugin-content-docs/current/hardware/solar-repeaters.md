# Արևային Լեռնային Ռետրանսլյատորների Կառուցում Հայաստանի Համար

Ինքնավար լեռնային և տանիքային ռետրանսլյատորները ձևավորում են Հայաստանի Meshtastic ցանցի հիմնական կմախքը՝ կապելով Երևանը շրջակա հովիտների, Սևանա լճի և լեռնանցքների հետ։

---

## 🏔️ Բնակլիմայական Պայմանները Հայաստանում

Հայաստանում ինքնավար ռետրանսլյատոր տեղադրելիս անհրաժեշտ է հաշվի առնել.
- **Ձմեռային Սառնամանիքներ**. Արագած լեռան, Գեղամա լեռների և հյուսիսային լեռնանցքների վրա ջերմաստիճանը իջնում է մինչև -20°C...-30°C։
- **Լիթիումի Լիցքավորման Սահմանափակումներ**. Սովորական լիթիում-իոնային (Li-Ion/Li-Po) մարտկոցները չի կարելի լիցքավորել 0°C-ից ցածր ջերմաստիճանում առանց վնասվելու կամ կարճ միացման վտանգի։
- **Ձյուն և Սառցակալում**. Ձյան հաստ շերտը կարող է ծածկել արևային վահանակները և կոտրել փխրուն անտեննաները։

---

## 🛠️ Առաջարկվող Ճարտարապետություն

```
[ 5W - 10W Արևային Վահանակ (Թրծված ապակի / IP67) ]
                         │
                         ▼
        [ RAK Wireless RAK4631 (nRF52840) ]
                         │
                         ▼
  [ LiFePO4 Մարտկոց կամ Ցրտադիմացկուն Li-Ion ] (18650 / 21700)
                         │
                         ▼
   [ 868 MHz Կարգավորված Ապակեպլաստե Անտեննա (3 - 5.8 dBi) ]
```

### 1. Էլեկտրոնիկա
- **Սալիկ**. **RAK Wireless WisBlock (RAK4631 + RAK19007)**։ Էներգասպառումը հանգիստ վիճակում 15 մԱ-ից պակաս է, ինչը թույլ է տալիս 3000 մԱ/ժ մեկ մարտկոցին աշխատել ավելի քան 8 օր ամբողջական մթության կամ բքի պայմաններում։
- **Դերը**. Կարգավորեք որպես **ROUTER** (կամ **ROUTER_CLIENT**, եթե տեղում անհրաժեշտ է Bluetooth կապ)։ Հին `REPEATER` դերը հնացած է։

### 2. Մարտկոցի Ընտրություն
- **LiFePO4 (Լիթիում-երկաթ-ֆոսֆատ)**. Շատ ավելի անվտանգ է և աշխատում է ջերմաստիճանի լայն տիրույթում (-20°C-ից մինչև +60°C)։
- **Ցրտադիմացկուն 18650 / 21700 Տարրեր**. Եթե օգտագործում եք սովորական Li-Ion, ապահովեք ջերմամեկուսացում տուփի ներսում։

### 3. Արևային Վահանակ
- **Հզորություն**. 5V / 6V՝ 5W-ից մինչև 10W հզորությամբ։
- **Անկյուն**. Տեղադրեք վահանակը 45°–60° անկյան տակ դեպի հարավ։ Սա ապահովում է առավելագույն էներգիա ձմռանը, երբ արևը ցածր է, և թույլ է տալիս ձյանը հեշտությամբ սահել։

### 4. Պաշտպանիչ Տուփ
- Պոլիկարբոնատից կամ ապակեպլաստից պատրաստված IP67 կամ IP68 տուփ։
- Հերմետիկ մալուխային մուտքեր (PG7 / PG9) սիլիկոնային քսուքով։
- Շնչող Gore-Tex փականներ (օր. Amphenol / Schreiner)՝ ճնշումը հավասարեցնելու և կոնդենսատը կանխելու համար։

# Ռետրանսլյատորներ, Դարպասներ և Բազային Կայաններ

Եթե շարժական սարքերը ծառայում են մասնակիցների անձնական կապի համար, ապա **անշարժ ռետրանսլյատորներն ու տնային դարպասները կազմում են Meshtastic Հայաստան ցանցի մշտական կմախքը**։ Արագած լեռան, Գեղամա լեռնաշղթայի կամ Երևանի բարձրահարկ շենքերի վրա տեղադրված հանգույցները փաթեթներ են փոխանցում մարզերի միջև։

---

## 1. Heltec WiFi LoRa 32 V4 — Իդեալական Տնային Դարպաս և Սեղանի Հանգույց

**Heltec V4** սալիկը մեծ առաջընթաց է նախորդ V3-ի համեմատ՝ նախագծված հզոր բազային կայանների, MQTT կամուրջների և տնային հանգույցների համար։

- **Միկրոկոնտրոլեր**. Espressif ESP32-S3 (Երկմիջուկ 240 MHz)
- **LoRa Տրանսիվեր**. Semtech SX1262
- **Ներկառուցված Հզորության Ուժեղացուցիչ (PA)**. Մեծացնում է հաղորդման հզորությունը մինչև **+28±1 dBm (~630 mW)** (հին V3 սալիկների ~20 dBm (~100 mW)-ի փոխարեն)։
- **Ցածր Աղմուկի Ուժեղացուցիչ (LNA)**. Ապահովում է ընդունման զգայունության մոտ **+3.8 dB** բարելավում՝ թույլ տալով որսալ հեռավոր գրպանային սարքերի ազդանշանները Երևանի ամբողջ տարածքում։
- **Էկրան**. Ներկառուցված 0.96″ մոնոխրոմ OLED
- **Կապ**. Wi-Fi 802.11 b/g/n, Bluetooth 5 LE, USB-C
- **Սնուցում**. Արևային վահանակի լիցքավորման ներկառուցված սխեմա և մարտկոցի կառավարում (BMS)։
- **Մոտավոր Գինը**. ~$22 – $28

### Կիրառումը Հայաստանում
- **Տնային MQTT Դարպաս**. Միացված է USB-C սնուցմանը և տան Wi-Fi-ին։ Այն փոխանցում է ռադիոփաթեթները համայնքային `mqtt.msh.am` սերվերին՝ թույլ տալով հարևան հանգույցներին երևալ [Ուղիղ Վահանակում](/dashboard)։
- **Քաղաքային Բազային Կայան**. Տանիքի 5.8 dBi անտեննայի հետ Heltec V4-ը կարող է ծածկել Երևանի, Գյումրիի կամ Վանաձորի ամբողջ թաղամասեր։

:::warning Ուշադրություն Firmware-ի ընտրությանը
Heltec V4-ի համար անհրաժեշտ է ընտրել հատուկ `heltec_v4` պրոֆիլը [Meshtastic Web Flasher](https://flasher.meshtastic.org/)-ում։ Մի տեղադրեք V3-ի ֆայլերը։
:::

## 2. RAK Wireless WisBlock Էկոհամակարգ — Ռետրանսլյատորների Համաշխարհային Ստանդարտ

Մոդուլային **RAK WisBlock** հարթակը ճանաչված առաջատարն է ինքնավար լեռնային և կայմային ռետրանսլյատորների համար.

- **Բազային Սալիկներ**. **RAK19007** (ստանդարտ) կամ **RAK19003** (կոմպակտ մինի)։
- **Պրոցեսորային Մոդուլ**. **RAK4631** (Nordic nRF52840 + Semtech SX1262)։
- **Էներգասպառում**. **15 մԱ-ից պակաս հանգիստ ռեժիմում**, ինչի շնորհիվ սարքը շաբաթներով աշխատում է ամպամած եղանակին։
- **Արևային Վահանակի Միացում**. Ուղիղ 5V ֆոտովահանակների միացում JST միակցիչով։
- **Պատյաններ**. Գործարանային ամենաեղանակային **RAK Unify IP67** բոքսեր՝ կայմի ամրակներով և N-տիպի անտեննային ելքերով։
- **Մոտավոր Գինը**. ~$40-ից մինչև ~$75 (ամբողջական արևային կոմպլեկտով)։

## 3. Heltec MeshTower — Պատրաստի Արևային Աշտարակ «Ամենը Մեկում»

Նրանց համար, ովքեր ցանկանում են պատրաստի արևային ռետրանսլյատոր առանց առանձին տուփեր հավաքելու և զոդելու.

- **Պրոցեսոր և Ռադիո**. Nordic nRF52840 + Semtech SX1262
- **Ներկառուցված Արևային Վահանակ**. 10W մոնոբյուրեղային վահանակ ալյումինե իրանի վրա։
- **Մարտկոցների Բլոկ**. Ներկառուցված 3-տարրանոց մարտկոց (~8400–9000 մԱ/ժ) արդյունաբերական BMS-ով։
- **Պաշտպանություն**. Անոդացված ալյումին, IP65/IP66 պաշտպանության աստիճան։
- **Ներկառուցված GNSS**. GPS՝ ռետրանսլյատորի դիրքը ավտոմատ որոշելու համար։
- **Մոտավոր Գինը**. ~$120 – $150

## 4. Ռետրանսլյատոր Heltec T114-ով — Բյուջետային Լեռնային Կառուցվածք մինչև $45

Եթե բյուջեն սահմանափակ է, հիանալի ինքնավար ռետրանսլյատոր կարելի է հավաքել **Heltec Mesh Node T114** սալիկի վրա ընդհանուր **մինչև $45** արժեքով.

```
[ 5V / 5W Կոմպակտ Արևային Վահանակ ]
                 │
                 ▼ (արևային մուտք)
  [ Heltec Mesh Node T114 (nRF52840) ]
                 │
                 ▼ (JST-GH միակցիչ)
  [ 18650 Li-Ion կամ 3.2V LiFePO4 Մարտկոց ]
                 │
                 ▼ (մալուխ IPEX -> SMA)
[ 868 MHz Կարգավորված Անտեննա (3 - 5.8 dBi) ]
```

### Բաղադրիչներ (BOM)
1. **Heltec T114 Սալիկ**. ~$25 (AliExpress)
2. **5V / 5W Վահանակ**. ~$8 – $12
3. **18650 կամ LiFePO4 Մարտկոց**. ~$4 – $7
4. **IP67 Տուփ**. ~$5 – $7 (շինանյութերի խանութից կամ Ozon-ից)
5. **Հերմետիկ Մուտքեր PG7 / PG9**. ~$1
6. **Կարգավորված Անտեննա 868 MHz**. ~$10 – $15

Nordic nRF52840 չիպի սպառումը կազմում է ընդամենը 12–15 մԱ, ուստի փոքր 5W վահանակը լիովին բավարար է շուրջտարյա անխափան աշխատանքի համար։

## ⚙️ Ռետրանսլյատորի Դերի Ընտրություն

- **`ROUTER`**. Մշտական լեռնային ռետրանսլյատորների համար՝ ուղիղ տեսանելիությամբ։ Առաջնահերթություն է տալիս փաթեթների վերահաղորդմանը և անջատում է Bluetooth-ը 15 րոպե անց՝ էներգիա խնայելու համար։
- **`ROUTER_CLIENT`**. Նման է `ROUTER`-ին, բայց Bluetooth-ը թողնում է միշտ միացված՝ հեռախոսով տեղում միանալու համար։
- **`CLIENT_MUTE`**. Տանիքի բարձր անտեննայով տնային դարպասների համար, որոնք միայն տվյալներ են հավաքում MQTT-ի համար։

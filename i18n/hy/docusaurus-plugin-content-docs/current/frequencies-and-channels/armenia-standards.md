# Հայաստանի Հաճախյության Ստանդարտներ (EU_868)

Հայկական Meshtastic համայնքը պաշտոնապես ստանդարտացրել է **EU_868 (868 MHz)** հաճախյության շերտը։

---

## Տեխնիկական Պարամետրեր

| Պարամետր | Արժեք Հայաստանում | Նոտա |
| :--- | :--- | :--- |
| **LoRa Տարածաշրջան** | `EU_868` | 868.0 MHz – 868.6 MHz (SRD/ISM) |
| **Լռածօրյա Կենտրոնային Հաճախյություն** | `869.525 MHz` | Slot 0 (`MediumFast` լռածօրյա) |
| **Մոդեմի Պրեսետ** | `MediumFast` | Ստանդարտացված համայն Հայաստանի համար |
| **Թողունակություն (BW)** | `250 kHz` | Լայն թողունակություն |
| **Տարածման Գործակից (SF)** | `9` | Արագ փոխանցման արագություն |
| **Կոդավորման Գործակից (CR)** | `4/5` | Սխալների ուղղում |
| **Առավելագույն Tx Հզորություն** | `27 dBm (500 mW)` | Ստանդարտ հեռարկման հզորություն |
| **Լռածօրյա Hop Սահմանափակ** | `3` | Կանխում է փաթեթի օղակները |

---

## Ինչու 868 MHz և ոչ 433 MHz?

1. **Անտեննայի Չափսեր**: 868 MHz անտեննաները կիսոն չափի են (~8.6 սմ), ավելի հարմար գրպանային սարքերի համար։
2. **RF Աղմուկ**: 433 MHz սպեկտրը Հայաստանի քաղաքներում ծանրաբեռնված է։
3. **Միջտարածաշրջանային Համատեղելիություն**: Վրաստանը, Եվրոպայի ճամորդները և հարևան տարածաշրջանային խմբերը նույնպես օգտագործում են `EU_868`։

---

## Գնման Ուղեցույց

Սարքավորում AliExpress-ից, Amazon-ից կամ այլ խանութներից գնելիս:
- Միշտ ընտրեք **868 MHz** կամ **915 MHz** տարբերակը։
- Մի **գնեք 433 MHz տարբերակը**, քանի որ այն ֆիզիկապես անհամատեղելի է Հայաստանի 868 MHz ցանցի հետ։

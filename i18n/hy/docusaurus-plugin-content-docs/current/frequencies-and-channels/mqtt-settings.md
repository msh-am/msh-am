# Համայնքային MQTT Դարպաս և Ուղիղ Քարտեզ

Meshtastic Հայաստանը ունի պաշտոնական MQTT բրոկեր (`mqtt.msh.am`), որը կապում է համայնքի հանգույցները **[Ուղիղ Mesh Վահանակի](/dashboard)** հետ։

---

## Վերաբերող Պարամետրեր

| Կարգավորում | Արժեք | Նոտա |
| :--- | :--- | :--- |
| **MQTT Enabled** | `ON` | Հիմնական անջատիչ (Options) |
| **Encryption Enabled** | `ON` | Options-ում՝ պահպանում է ալիքի փաթեթների ծածկագրումը |
| **Server Address** | `mqtt.msh.am` | Համայնքային բրոկեր |
| **Server Port** | `1883` | Ստանդարտ MQTT պորտ |
| **TLS Enabled** | `OFF` | Server-ում՝ TLS չի օգտագործվում 1883 պորտի համար |
| **Username** | `meshdev` | Համայնքային մուտք |
| **Password** | `large4cats` | Ստանդարտ գաղտնաբառ |
| **Root Topic** | `/msh/EU_868/AM/` | Տարածաշրջանային թեմա |
| **Uplink** | `YES` | Միացրեք |
| **Downlink** | **`NO`** | **ԿԱՌԵՎՈՌ: Երբեք մի միացրեք** |

---

:::danger Երբեք մի միացրեք Downlink հանգույցների վրա!
- **Uplink (RF -> MQTT)**: Սարքը րադիոյից ստացված փաթեթը ուղղում է ինտերնետի վահանակին։ Սա անվտանգ է։
- **Downlink (MQTT -> RF)**: Սարքը ինտերնետից ստացված թրաֆիկը **վերահեռարկում է տեղական 868 MHz ռադիոյով**: սա կհաղետի տեղական սպեկտրը։
:::

---

## 🔒 Գաղտնիություն և Հանրային Uplink Կառավարում

- **`OkToMQTT`**: Խնդրեք ձեր հանգույցը համաշխարհային քարտեզին ուղղելու համար։
- **`ignore_mqtt`**: Լիովին RF ռադիոյով կապի համար, առանց ինտերնետ ուղղորդման։

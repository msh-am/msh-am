# Каналы и шифрование в армянской сети

Узлы Meshtastic поддерживают до 8 одновременных каналов (1 первичный и до 7 вторичных). В сети Армении конфигурация каналов стандартизирована для баланса доступности, приватности и чистоты радиоэфира.

---

## 1. Основной публичный канал (`MediumFast`)

Главный канал сообщества для общих сообщений, обнаружения узлов, обмена координатами и открытого общения:

- **Имя канала**: `MediumFast`
- **Общий ключ (PSK)**: `AQ==` (стандартный открытый ключ)
- **Роль**: `PRIMARY`
- **Пресет модема**: `MediumFast`
- **Частотный слот**: Слот 0 (`869.525 МГц` в `EU_868`)
- **Полоса / SF / CR**: 250 кГц / SF9 / CR 4/5
- **Ограничение пересылок (Hop Limit)**: `3`
- **Uplink**: `YES` (для передачи данных на общественную карту по MQTT)
- **Downlink**: ❌ `NO` (строго отключён на клиентских узлах во избежание перегрузки радиоэфира)

:::note Автоматическое подключение
Ключ `AQ==` означает открытый незашифрованный канал. Любой узел с регионом `EU_868` и пресетом `MediumFast` автоматически подключается к этому каналу при включении.
:::

---

## 2. Аварийный канал (`Emergency-AM`)

Выделенный вторичный канал для сигналов бедствия в горах, предупреждений о стихийных бедствиях и координации поисково-спасательных операций:

- **Имя канала**: `Emergency-AM`
- **Общий ключ (PSK)**: `AQ==` (открытый)
- **Роль**: `SECONDARY`
- **Назначение**: Массив Арагац, Гегамский хребет, горные походы и экстренные оповещения.

:::tip Телеметрия передаётся в основном канале
В сети Армении **не используется** отдельный канал `Telemetry-AM`. Вся телеметрия передаётся по основному каналу. Соблюдайте правила снижения частоты отправки телеметрии.
:::

## 3. Приватные зашифрованные каналы

Для семей, экспедиций, частных групп или волонтёрских команд:

1. В приложении Meshtastic откройте **Channels** -> **Add Channel**.
2. Введите имя канала (например, `Family` или `HikeTeam`).
3. Нажмите **Generate Key** для создания криптографически стойкого ключа **AES-256**.
4. Поделитесь каналом с доверенными участниками через **QR-код** или ссылку.

### Как работают приватные каналы через LoRa
При отправке сообщения в зашифрованный канал все промежуточные узлы сети (включая горные ретрансляторы на Арагаце или Севане) **пересылают ваши пакеты без расшифровки**. Прочитать сообщение могут только устройства с вашим уникальным ключом AES-256.

## 4. Чистота эфира: оптимизация GPS и телеметрии

В общем радиоэфире каждая передача занимает время. Неоптимизированные узлы создают коллизии:

### A. Интервалы отправки координат GPS
- **Включите Smart Position (для носимых узлов)**:
  - В приложении: **Settings** -> **Position** -> включите **Smart Position**.
  - Передача прекращается в покое и активируется только при реальном перемещении (например, более 100 метров).
- **Стационарные домашние узлы (`CLIENT_BASE`, `CLIENT_MUTE`)**:
  - Установите **Fixed Position** вручную или увеличьте интервал GPS до **30–120 минут** (1800–7200 сек).

### B. Отключение телеметрии на домашних узлах
- **Домашние узлы с постоянным питанием от USB**:
  - В **Settings** -> **Telemetry**: отключите Device Metrics или увеличьте интервал до **2–6 часов**. Рассылка статуса «100% батареи» каждые пару минут бесполезна и засоряет эфир.
- **Узлы без аккумулятора**:
  - Если плата питается от USB без батареи, выключите телеметрию батареи, чтобы не спамить значениями 0V / 0%.
- **Датчики окружающей среды**:
  - Отключайте опрос сенсоров, если физические модули (BME280/BMP280/SHT31) не установлены. При их наличии задайте интервал **30–60 минут**.

## 5. Интеграция с MQTT и онлайн-панелью

Если стационарный узел подключён к домашнему Wi-Fi, подключите его к серверу сообщества для отображения на [онлайн-панели](/dashboard):

- **Сервер**: `mqtt.msh.am`
- **Топик**: `/msh/EU_868/AM/`
- **Uplink**: `YES`
- **Downlink**: ❌ `NO`

👉 Подробные инструкции см. в **[Руководстве по настройке MQTT](/docs/frequencies-and-channels/mqtt-settings)**.

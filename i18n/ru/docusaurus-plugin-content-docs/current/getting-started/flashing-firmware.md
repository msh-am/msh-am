# Как прошить Meshtastic через браузер

Прошивку Meshtastic можно установить и обновить прямо из браузера через Web Serial с помощью Google Chrome, Microsoft Edge или Brave.

---

## Требования

1. **Компьютер**: Windows, macOS или Linux.
2. **Браузер**: Google Chrome, Microsoft Edge или Brave (Safari и Firefox не поддерживают Web Serial API).
3. **Качественный USB-кабель**: Убедитесь, что кабель поддерживает передачу данных, а не только зарядку.
4. **Подключённая антенна**:

:::danger НИКОГДА не включайте LoRa-плату без подключённой антенны!
Передача без нагрузки вызывает высокое значение КСВ (VSWR) и отражение мощности назад в микросхему, что может мгновенно сжечь выходной усилитель мощности (PA).
:::

---

## Пошаговая инструкция (Web Flasher)

### Шаг 1. Откройте официальный прошивальщик
Перейдите на: **[flasher.meshtastic.org](https://flasher.meshtastic.org)**

### Шаг 2. Подключите устройство по USB
Подключите плату к компьютеру. Если система не определяет COM-порт:
- Установите драйвер **CP210x USB to UART Bridge VCP Driver** (платы Heltec и LilyGO).
- Либо установите драйвер **CH340 / CH9102**.

### Шаг 3. Выберите модель устройства и версию прошивки
1. Выберите архитектуру вашей платы (например, `Heltec V3`, `Heltec V4`, `LilyGO T-Beam`, `RAK4631`).
2. Выберите последнюю стабильную версию прошивки (**Stable**).

### Шаг 4. Прошивка и проверка
1. Нажмите кнопку **Flash**.
2. Во всплывающем окне выберите соответствующий COM-порт и нажмите **Connect**.
3. Дождитесь очистки памяти и записи прошивки (~60–90 секунд).
4. По завершении устройство перезагрузится с логотипом Meshtastic на экране.

## Устройства на nRF52 (Метод UF2 Drag & Drop)

Для плат на чипе Nordic nRF52 (**RAK Wireless WisBlock RAK4631** или **LilyGO T-Echo**):
1. Подключите устройство кабелем USB.
2. Быстро дважды нажмите аппаратную кнопку **Reset**.
3. Устройство определится компьютером как съёмный USB-накопитель (например, `RAK4631` или `NICENANO`).
4. Скачайте файл прошивки `.uf2` со страницы [релизов Meshtastic на GitHub](https://github.com/meshtastic/firmware/releases).
5. Перетащите `.uf2` файл на накопитель. Устройство автоматически прошьётся и перезагрузится.
